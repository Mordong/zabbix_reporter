## Как принять участие

Проект открыт для предложений и улучшений. Если вы хотите внести вклад:

1. **Сообщить об ошибке** — отправьте описание проблемы автору на e-mail. Желательно приложить:
   - Версию приложения (видна в заголовке окна)
   - Версию Zabbix
   - Сообщение из окна «📋 Лог / Отладка» (кнопка «💾 Сохранить» сохранит его в `.txt`)
   - Шаги для воспроизведения

2. **Предложить улучшение** — кратко опишите идею и сценарий использования. Если есть прототип — приложите.

3. **Прислать патч** — поделитесь diff-файлом или модифицированным `zabbix_reporter.py` с описанием изменений.

---

## Стиль кода

- Python 3.8+ совместимость
- Кодировка исходников — **UTF-8**
- Отступы — **4 пробела**, без табов
- Длина строки — желательно ≤ 100 символов
- Комментарии и сообщения в логах — на русском
- Имена методов и переменных — на английском, в `snake_case`

---

## Проверка перед отправкой

Перед отправкой изменений убедитесь, что:

- [ ] Файл проходит синтаксическую проверку (`python -m py_compile zabbix_reporter.py`)
- [ ] Приложение запускается через `run.bat`
- [ ] EXE собирается без ошибок через `build.bat`
- [ ] Новый функционал отражён в `CHANGELOG.md`
- [ ] Версия приложения обновлена (docstring, `App.__init__`, заголовок `_build_ui`)
