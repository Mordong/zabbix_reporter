# ⚡ Zabbix Reporter v3.0

Десктопное приложение для Windows 10/11 для работы с Zabbix 6.x / 7.x через JSON-RPC API.  
Получение данных мониторинга, сравнение шаблонов, поиск дубликатов, экспорт в **PDF / Excel / CSV / YAML / JSON** с полной поддержкой кириллицы.

## Что нового в v3.0

- 🆕 **Объединённая вкладка «Хосты»** — список и детальная карточка в одном месте, открытие карточки в отдельном окне по двойному клику

- 🆕 **Вкладка «🔎 Дубликаты»** — поиск дубликатов хостов по имени, формату (short/FQDN) и IP
- 🆕 **Вкладка «⚖ Сравнение шаблонов»** — трёхуровневый алгоритм сравнения Items, Triggers и Discovery Rules

## Требования

| Компонент | Версия |
|-----------|--------|
| Python | 3.8 – 3.14 |
| Windows | 10 / 11 (x64) |
| Zabbix | 6.0 – 7.x |

**Обязательные зависимости** (устанавливаются автоматически через `run.bat`):

```
openpyxl  >= 3.1.0   — экспорт Excel
reportlab >= 4.0.0   — экспорт PDF
matplotlib >= 3.7.0  — графики метрик
```

Приложение запускается и без этих библиотек — с ограниченным функционалом.

## Сборка EXE

Для создания standalone-исполняемого файла (Python на целевом ПК не нужен):

```bat
1. Дважды кликните build.bat
2. Готовый файл появится в папке  dist\ZabbixReporter.exe
3. Скопируйте на любой Windows 10/11 ПК
```

**Примечания:**
- Первый запуск `.exe` занимает 5–10 секунд (распаковка в temp)
- Антивирус может ложно срабатывать на PyInstaller-бинарники — добавьте папку `dist\` в исключения

#### 🖥 Хосты

Объединённая вкладка со списком хостов и детальной карточкой.

**Тулбар:**
- **Фильтр по группе** — выпадающий список всех групп хостов
- **Фильтр по шаблону** — выпадающий список шаблонов
- **Поиск 🔍** — поиск по любой колонке в реальном времени
- **🔄 Обновить расширенно** — догружает шаблоны, макросы, теги, версию агента

**Таблица (10 колонок):**

| Колонка | Описание |
|---------|----------|
| Хост | Техническое имя |
| Имя | Visible name |
| Группы | Все группы хоста через запятую |
| Шаблоны | Все шаблоны хоста |
| Статус | Enabled / Disabled |
| **Доступн.** | Available / Unavailable / Unknown |
| **Интерфейсы** | Все интерфейсы с типом и адресом: `Agent 192.168.1.10:10050 ●  SNMP 10.0.0.5:161` |
| **Agent ver.** | Версия Zabbix agent (из item `agent.version`) |
| Тригг. | Количество триггеров |
| Обслуж. | 🔧 + имя maintenance периода |

**Цветовая индикация строк:**
- 🟢 зелёный — доступен
- 🔴 красный — недоступен
- 🟡 жёлтый — статус неизвестен
- 🟠 оранжевый — в обслуживании

**Алгоритм определения доступности:**
1. Если интерфейс типа Agent — берётся `interface.available`
2. Для SNMP/IPMI/JMX, когда `interface.available = 0` (Unknown) — проверяется свежесть данных: есть ли хотя бы один item с `lastclock` за последние 15 минут
3. Если интерфейсов нет — fallback на устаревшее поле `host.available`

**Карточка хоста** (двойной клик или Enter по строке) — модальное окно с:
- **Основное:** Host name, Visible name, Enabled, Monitored by, Description, статус обслуживания
- **Host groups** — все группы
- **Templates** — все привязанные шаблоны
- **Interfaces** — каждый интерфейс с типом, адресом, портом, флагом «основной» и статусом доступности (✓/✗/?)
- **Zabbix agent ver** — версия агента для Agent-интерфейсов
- **Tags** — теги хоста с значениями
- **Host macros** — макросы с типом (Secret скрыт как `***`) и описаниями

#### 📋 События

История событий с гибкой фильтрацией:

**Тулбар — фильтры:**
- **Серьёзность** — 6 чекбоксов для каждого уровня
- **Хост** — выпадающий список уникальных хостов (заполняется автоматически)
- **Время С / По** — формат `YYYY-MM-DD HH:MM` (пустые поля = без ограничения)
- **🔍 Применить** / **⟲ Сброс**

Фильтры работают на уже загруженных данных без повторного запроса к API.

**Таблица (7 колонок):**

| Колонка | Описание |
|---------|----------|
| ID | Event ID |
| Серьёзность | Уровень с цветовой индикацией |
| Событие | Описание события (из триггера) |
| Хост | Имя хоста |
| Время | Когда сработало |
| **Восст.** | Время восстановления (из recovery event) или `—` |
| **Длит.** | Длительность от начала до восстановления (или до «сейчас») |

**Важно:** Время восстановления получается через отдельный запрос к `event.get` для recovery-событий и сопоставляется через `r_eventid` — это обходит ограничение Zabbix API когда `value: 1` не возвращает `r_clock`.

#### 🔐 Аутентификация

Просмотр и экспорт конфигурации аутентификации Zabbix.

**Тулбар:**
- **🔄 Загрузить** — получает `authentication.get` и `userdirectory.get`
- **💾 Выгрузить в файл** — одновременно создаёт JSON и PDF

**Левая панель** — список LDAP/SAML серверов:
| Имя | Тип | JIT |
|-----|-----|-----|
| AD Main | LDAP | Да |
| SAML Okta | SAML | Да |

**Правая панель** показывает детальную карточку:

**Глобальные настройки:**
- Метод аутентификации по умолчанию (Internal / LDAP / HTTP)
- Парольная политика (минимальная длина, требования к сложности)
- HTTP аутентификация (статус, strip domains, case sensitive)
- SAML (статус, JIT, case sensitive)
- MFA статус

**Карточка LDAP-сервера:**
- **Подключение:** Host, Port, Base DN, Bind DN, Bind password, StartTLS
- **Поиск пользователей:** Search attribute
- **JIT Provisioning:**
  - Group configuration (memberOf / groupOfNames)
  - Group base DN, Group name attr, Group member attr
  - User username / lastname attributes, User ref attr, Group filter
  - **User Group Mapping** — LDAP паттерн → Zabbix Role → Zabbix группы
  - **Media Type Mapping** — атрибут LDAP → тип медиа, active, severity, period
- **SAML:** IDP Entity ID, SSO/SLO URL, подписи и шифрование, SCIM

Имена ролей, групп и типов медиа разрешаются автоматически через API.

**Экспорт:**
- **JSON** — полный дамп `authentication.get` + `userdirectory.get` с именами ролей/групп/медиа
- **PDF** — форматированный отчёт с таблицами: глобальные настройки, параметры каждого сервера, group/media mapping, кириллица

#### ⚖ Сравнение шаблонов

Сравнение двух шаблонов с трёхуровневым алгоритмом.

**Использование:**
1. Нажмите **🔄 Загрузить шаблоны**
2. Выберите **Шаблон A** и **Шаблон B** из выпадающих списков
3. Нажмите **⚖ Сравнить**
4. Результат отображается на пяти подвкладках:
   - 📊 **Items**
   - ⚡ **Triggers**
   - 🔍 **Discovery Rules**
   - 📊 **Item Prototypes**
   - ⚡ **Trigger Prototypes**
5. Нажмите **📄 PDF** или **📋 CSV** для экспорта

**Алгоритм сравнения (трёхуровневый):**

| Уровень | Метод | Пример |
|---------|-------|--------|
| 1 | Точное совпадение по имени | `CPU utilization` == `CPU utilization` |
| 2 | Совпадение по ключу | разные имена, но одинаковый `system.cpu.util` |
| 3 | Нечёткое совпадение (≥ 72%) | `Free memory` ~ `Available memory` |

**Статусы строк:**

| Цвет | Статус | Значение |
|------|--------|----------|
| 🔴 Красный | Только A | Есть только в шаблоне A |
| 🟢 Зелёный | Только B | Есть только в шаблоне B |
| 🟡 Жёлтый | Различия | Одинаковое имя, но отличаются параметры |
| 🟠 Оранжевый | Похожие | Схожие имена, найдено нечётким поиском |
| ⬜ Серый | Совпадает | Полное совпадение |

**Сравниваемые параметры:**
- Items / Item Prototypes: `key_`, `type`, `value_type`, `delay`, `units`, `status`
- Triggers / Trigger Prototypes: `expression`, `priority`, `status`, `recovery_mode`
- Discovery Rules: `key_`, `type`, `delay`, `status`

#### 📤 Экспорт шаблонов

Массовый экспорт шаблонов в YAML / XML / JSON.

**Использование:**
1. Нажмите **🔄 Загрузить список**
2. Отметьте шаблоны тиками (клик по строке) или кнопкой **☑ Выбрать все**
3. Выберите формат: **YAML** / **XML** / **JSON**
4. Нажмите **📤 Экспортировать выбранные** и выберите папку

Каждый шаблон сохраняется в **отдельный файл**, имя файла = имя шаблона:

```
dist/
├── Linux by Zabbix agent.yaml
├── Windows by Zabbix agent.yaml
├── Mikrotik by SNMP.yaml
└── Zabbix server health.yaml
```

Спецсимволы в именах заменяются на `_`. Формат YAML рекомендуется для Zabbix 5.4+.

#### 🔎 Дубликаты

Поиск дубликатов хостов по двум категориям (работает на уже загруженных хостах, без запросов к API).

**Использование:**
1. Убедитесь что хосты загружены (кнопка «🔄 Обновить все данные» в левой панели)
2. Перейдите во вкладку **🔎 Дубликаты**
3. Нажмите **🔍 Найти дубликаты**
4. Настройте фильтры (чекбоксы типов)
5. Клик по группе → показ всех хостов в ней

**Алгоритм обнаружения:**

| Тип | Логика | Пример |
|-----|--------|--------|
| 🟡 **По hostname** | Совпадает short-name (до первой точки) в нижнем регистре | `Server01` и `server01`  <br> `yac-vl-0001` и `yac-vl-0001.domain.net` |
| 🔴 **По IP** | Одинаковый IP в интерфейсах **одного типа** | Два хоста с `Agent:192.168.1.10` |

Причина дубликата автоматически классифицируется:
- «разный регистр»
- «short vs FQDN»
- «разные варианты написания»
- «точные дубликаты»

**Интерфейс:**
- **Левая панель** — список групп дубликатов с типом, описанием и количеством хостов
- **Правая панель** — таблица всех хостов в выбранной группе: Host name, Visible name, Группы, IP / интерфейсы, Статус, Доступность

**Экспорт:**
- **📄 PDF** — цветные таблицы с группировкой по типу, сводная статистика на первой странице
- **📋 CSV** — один файл со всеми группами (UTF-8 BOM для Excel)

## История изменений

**Хосты и Объекты:**
- Объединение вкладок «Хосты» и «Объекты» в одну
- Новая колонка **Agent version** прямо в таблице
- Карточка хоста открывается в **отдельном окне** по двойному клику

- Колонка **Интерфейсы** показывает все интерфейсы с типом и адресом

**События:**
- Фильтры по **серьёзности** (6 чекбоксов), **хосту** и **временному интервалу**
- Корректное получение **времени восстановления** через recovery-события

**Дубликаты:**
- Объединение «По имени» и «Short/FQDN» в единую категорию **«По hostname»**

- Причина дубликата автоматически классифицируется

**Шаблоны:**
- Вкладка **Сравнение шаблонов** с трёхуровневым алгоритмом

- Кнопка «Загрузить шаблоны» в обеих вкладках

**Аутентификация:**
- Кнопка **💾 Выгрузить в файл** — одновременный экспорт в PDF и JSON
- Полная поддержка JIT Provisioning (group mapping, media mapping)
- Поддержка Zabbix 6.4+ через `selectProvisionGroups` / `selectProvisionMedia`

**UI/UX:**
- Увеличен размер окна до `1540×860` (минимум `1200×700`)
- Уменьшен padding вкладок — не сжимается текст
- Исправлен стиль Combobox (текст виден во всех состояниях)
- Коллапсируемые секции в левой панели через `grid_remove` (разворачиваются в правильном месте)

**Исправления:**
- `matplotlib.use("Agg")` больше не ломает `FigureCanvasTkAgg` — график строится корректно
- Исправлен дубликат `fontName` в `ParagraphStyle` экспорта сравнения
- Исправлена рекурсия при загрузке списка шаблонов
- Исправлена ошибка «Item not found» в `_tpl_exp_select_all`
- Поддержка `selectHostGroups` / `selectTemplateGroups` (Zabbix 6.2+) с fallback

### v2.x (накопленные изменения)

- Вкладка 🔐 Аутентификация
- Доступность хостов через интерфейсы (не устаревшее поле `host.available`)

## Известные ограничения

- **Права пользователя:** для `authentication.get` / `userdirectory.get` требуется **Super Admin**; для базовых данных достаточно **Zabbix User**
- **Графики метрик** требуют `matplotlib`; без него кнопка «Построить график» не работает
- **YAML-экспорт** поддерживается начиная с Zabbix 5.4; для более старых версий автоматически используется XML
- **JIT Provisioning** в API поддерживается начиная с Zabbix 6.4; на более ранних версиях поля `provision_groups` / `provision_media` будут пустыми
- **Latest data check** — доступность не-Agent хостов определяется по свежим данным за последние 15 минут
- **Лимит записей** применяется к проблемам и событиям

## Диагностика неполадок

### Список шаблонов пустой
- Убедитесь что подключение активно (статус «● Подключено» в правом верхнем углу)
- Проверьте права пользователя — нужен минимум **Zabbix User** с доступом к хостгруппам
- Откройте **📋 Лог / Отладка** (кнопка внизу) — там видна точная причина

### «auth» unexpected parameter
Zabbix 7.0+ использует Bearer-авторизацию. Ошибка возникает если auth-токен передаётся через body. Уже исправлено — обновите до актуальной версии.

### `Item 10380 not found` при выборе всех шаблонов
Исправлено: теперь `_tpl_exp_select_all` итерирует реально вставленные строки, а не загруженный список данных.

### График метрик не строится
Проверьте установлен ли matplotlib:
```bat
pip install matplotlib
```
В старых версиях `matplotlib.use("Agg")` ломал TkAgg backend — исправлено.

### Доступность всех хостов «Unknown»
Это нормально для SNMP/IPMI/JMX хостов — поле `interface.available` у них часто `0`. Нажмите **🔄 Обновить расширенно** во вкладке Хосты — проверится latest data.

### Кириллица в PDF как квадраты
Приложение автоматически ищет TTF-шрифты в `C:\Windows\Fonts\` (Arial, Calibri, Segoe UI). Если ни один не найден — fallback на Helvetica без кириллицы. Установите любой TTF из указанных.

### Антивирус блокирует .exe
PyInstaller-бинарники иногда ложно детектируются. Добавьте папку `dist\` в исключения антивируса или подпишите `.exe` своим сертификатом.
