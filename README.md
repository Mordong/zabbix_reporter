# ⚡ Zabbix Reporter v3.0

Десктопное Windows-приложение для получения данных из Zabbix 6.x / 7.x через JSON-RPC API.  
Экспорт отчётов в **PDF**, **Excel (.xlsx)** и **CSV** с поддержкой кириллицы.

## Требования

| Компонент | Версия |
|-----------|--------|
| Python | 3.8 – 3.14 |
| Windows | 10 / 11 (x64) |
| Zabbix | 6.0 – 7.x |

**Обязательные зависимости** (устанавливаются автоматически через `run.bat`):

```
openpyxl  >= 3.1.0   — экспорт Excel
reportlab >= 4.0.0   — экспорт PDF
matplotlib >= 3.7.0  — графики метрик (необязательно)
```

Приложение работает и без этих библиотек — с ограниченным функционалом экспорта.

```bat

```

## Сборка EXE

Для создания standalone-исполняемого файла (Python на целевом ПК не нужен):

```bat
1. Дважды кликните build.bat
2. Готовый файл появится в папке  dist\ZabbixReporter.exe  (~50–70 МБ)
3. Файл можно скопировать на любой Windows 10/11 ПК
```

**Примечание:** При первом запуске `.exe` распаковывается во временную папку — это нормально, занимает 5–10 секунд. Антивирус может ложно срабатывать на PyInstaller-бинарники — добавьте папку `dist\` в исключения.

## Интерфейс

### Левая панель

Сворачиваемые секции (клик по заголовку):

#### 🔌 Подключение
- **URL сервера** — адрес Zabbix frontend (`http://...` или `https://...`)
- **Пользователь / Пароль** — учётные данные Zabbix (не LDAP bind-пользователь)
- **Проверять SSL** — отключить для самоподписанных сертификатов
- Кнопки: **Подключиться / Отключиться / Сохранить настройки**

Настройки автоматически сохраняются в `config.json` рядом с файлом приложения.

#### ⚙ Фильтры
- **Мин. серьёзность** — фильтр проблем (Not classified / Information / Warning / Average / High / Disaster)
- **Лимит записей** — максимум строк при загрузке (по умолчанию 500)
- **Период С / По** — диапазон дат для событий (формат `YYYY-MM-DD`)
- **Обновить все данные** — загрузить Проблемы, Хосты, События
- **Диагностика API** — проверить права пользователя и связь с API

#### 💾 Экспорт
- **Экспорт PDF** — выбор разделов → сохранение PDF
- **Экспорт Excel** — выбор разделов → сохранение XLSX
- **Экспорт CSV** — сохранение всех данных в CSV файлы

### Вкладки данных

#### 🔴 Проблемы
Список активных проблем с полями: серьёзность, имя, хост, время начала, длительность, подтверждения.  
Цветовая индикация по серьёзности. Сортировка по любому столбцу. Поиск в реальном времени.

#### 🖥 Хосты
Сводная таблица хостов:
- **Хост / Имя** — техническое и видимое имя
- **Группа** — группы хостов
- **Статус** — Enabled / Disabled
- **Доступность** — вычисляется из `interfaces[].available` (Zabbix 6.0+, не устаревшее поле `host.available`)
- **Интерфейсы** — все интерфейсы со статусом: `Agent·✓`, `SNMP·✗`, `IPMI·?`
- **Тригг.** — количество триггеров
- **Обслуж.** — статус обслуживания с именем периода (🔧)

Цвета строк: зелёный = доступен, красный = недоступен, жёлтый = неизвестно, оранжевый = в обслуживании.

#### 📋 События
История событий за выбранный период. Поля: ID, серьёзность, описание, хост, время, время восстановления.

#### 📈 Метрики
Просмотр и построение графиков метрик по выбранному хосту:
1. Выберите хост из выпадающего списка
2. Опционально введите поисковый запрос
3. Нажмите **Загрузить метрики**
4. Выберите одну или несколько метрик в таблице
5. Нажмите **Построить график** — график строится прямо в приложении

#### 🗂 Объекты мониторинга
Расширенный просмотр хостов с полной карточкой. Фильтрация по группе, шаблону и тексту.

**Карточка хоста** показывает:
- **Host name / Visible name** — имена
- **Enabled** — статус включения
- **Monitored by** — имя прокси или «Zabbix Server»
- **Host groups** — все группы хоста
- **Templates** — привязанные шаблоны
- **Interfaces** — все интерфейсы с типом, адресом и портом
- **Zabbix agent version** — версия агента (если интерфейс типа Agent и данные доступны)
- **Tags** — теги хоста с значениями
- **Host macros** — макросы с типом (Text / Secret / Vault) и описанием

#### 🔐 Аутентификация
Просмотр конфигурации аутентификации Zabbix. Нажмите **Загрузить** для получения данных.

**Глобальные настройки:**
- Метод аутентификации по умолчанию (Internal / LDAP / HTTP)
- Парольная политика (минимальная длина, требования к сложности)
- HTTP аутентификация (статус, strip domains, case sensitive)
- SAML (статус, JIT, case sensitive)
- MFA статус

**Карточка LDAP-сервера** (при выборе в списке):
- **Подключение:** Host, Port, Base DN, Bind DN, Bind password, StartTLS
- **Поиск пользователей:** Search attribute
- **JIT Provisioning:**
  - Group configuration (memberOf / groupOfNames)
  - Group base DN, Group name attr, Group member attr
  - User username / lastname attributes, User ref attr, Group filter
  - **User Group Mapping** — LDAP паттерн → Zabbix Role → Zabbix группы (с именами)
  - **Media Type Mapping** — атрибут LDAP → тип медиа, active, severity, period
- **SAML:** IDP Entity ID, SSO/SLO URL, подписи и шифрование, SCIM

Имена ролей, групп и типов медиа разрешаются автоматически через API.

#### ⚖ Сравнение шаблонов
Сравнение двух шаблонов по пяти категориям с экспортом в PDF и CSV.

**Использование:**
1. Выберите **Шаблон A** и **Шаблон B** из выпадающих списков
2. Нажмите **⚖ Сравнить**
3. Результат отображается на пяти подвкладках: Items, Triggers, Discovery Rules, Item Prototypes, Trigger Prototypes
4. Нажмите **📄 PDF** или **📋 CSV** для экспорта

**Алгоритм сравнения (трёхуровневый):**

| Уровень | Метод | Пример |
|---------|-------|--------|
| 1 | Точное совпадение по имени | `CPU utilization` == `CPU utilization` |
| 2 | Совпадение по ключу | разные имена, но одинаковый `system.cpu.util` |
| 3 | Нечёткое совпадение (≥ 72%) | `Free memory` ~ `Available memory` |

**Статусы строк:**

| Цвет | Статус | Значение |
|------|--------|----------|
| 🔴 Красный | Только A | Элемент есть только в шаблоне A |
| 🟢 Зелёный | Только B | Элемент есть только в шаблоне B |
| 🟡 Жёлтый | Различия | Одинаковое имя, но отличаются параметры (key, type, delay и др.) |
| 🟠 Оранжевый | Похожие | Схожие имена, найдено нечётким поиском |
| ⬜ Серый | Совпадает | Полное совпадение |

**Сравниваемые параметры:**
- Items / Item Prototypes: `key_`, `type`, `value_type`, `delay`, `units`, `status`
- Triggers / Trigger Prototypes: `expression`, `priority`, `status`, `recovery_mode`
- Discovery Rules: `key_`, `type`, `delay`, `status`

#### 📤 Экспорт шаблонов
Массовый экспорт шаблонов в YAML / XML / JSON файлы.

**Использование:**
1. Нажмите **🔄 Загрузить список** (или перейдите в эту вкладку после «Обновить все данные»)
2. Выберите шаблоны тиками (клик по строке) или кнопкой **☑ Выбрать все**
3. Выберите формат: **YAML** / **XML** / **JSON**
4. Нажмите **📤 Экспортировать выбранные** и выберите папку

Каждый выбранный шаблон сохраняется в **отдельный файл**:
```
Имя шаблона.yaml
Linux by Zabbix agent.yaml
Windows by Zabbix agent.yaml
Mikrotik by SNMP.yaml
```

Спецсимволы в именах заменяются на `_`. Формат YAML рекомендован для Zabbix 6.2+.

#### 📊 Сводка
Текстовый отчёт по загруженным данным: распределение проблем по серьёзности, доступность хостов, количество событий.

## Экспорт отчётов

### Диалог выбора разделов

При нажатии «Экспорт PDF» или «Экспорт Excel» открывается диалог с выбором разделов:

| Раздел | PDF | Excel |
|--------|-----|-------|
| 🔴 Активные проблемы | ✓ | ✓ (лист «Проблемы» + диаграмма) |
| 🖥 Статус хостов | ✓ | ✓ (лист «Хосты») |
| 📋 История событий | ✓ | ✓ (лист «События») |
| 🗂 Объекты мониторинга | ✓ | ✓ (лист «Объекты мониторинга») |
| 🔐 Аутентификация / LDAP | ✓ | ✓ (листы «Аутентификация» + по LDAP-серверу) |
| 📈 Графики метрик | ✓ | ✓ (листы «М:…») |

Выбор сохраняется в `config.json`.

### PDF
- Формат A4, кириллица через системный TTF-шрифт (Arial / Calibri / Segoe UI)
- Автоматический fallback на Helvetica при отсутствии TTF
- Пропорциональные ширины колонок — таблицы всегда помещаются на страницу
- Сравнение шаблонов генерируется в альбомном формате A4

### Excel (.xlsx)
- Отдельный лист на каждый раздел
- Стилизованные заголовки, чередующиеся строки, условное форматирование
- Диаграммы для проблем по серьёзности
- LDAP: отдельные листы для параметров сервера, group mapping и media mapping

### CSV
- UTF-8 с BOM (корректно открывается в Microsoft Excel)
- Отдельный файл для каждого раздела

## Известные ограничения

- **Аутентификация** — требуется учётная запись типа **Super admin** для доступа к `authentication.get`, `userdirectory.get`; для базовых данных достаточно **Zabbix User**
- **Графики метрик** — требуется библиотека `matplotlib`; без неё вкладка работает, но кнопка «Построить график» неактивна
- **YAML-экспорт** — поддерживается начиная с Zabbix 5.4; для более старых версий автоматически используется XML
- **JIT Provisioning** в API — поддерживается начиная с Zabbix 6.4; на более ранних версиях поля `provision_groups` / `provision_media` будут пустыми
- **Фоновое провижинирование** — в Zabbix выполняется только когда пользователь активно работает с frontend, не фоновым процессом
- **Лимит записей** применяется к проблемам; события также ограничены этим значением
