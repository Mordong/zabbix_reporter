# Zabbix Reporter — Windows 10/11

Десктопное приложение для получения отчётов из **Zabbix 7.x** через **JSON-RPC API**.

## Возможности

| Раздел | Данные |
|---|---|
| 🔴 Проблемы | Активные алерты с серьёзностью, длительностью, подтверждениями |
| 🖥 Хосты | Статус, доступность, IP, группы, количество триггеров |
| 📋 События | История проблем за выбранный период |
| 📊 Сводка | Агрегированная статистика по серьёзности и доступности |

## Экспорт

- **Excel (.xlsx)** — цветовое выделение по серьёзности, автофильтры, заморозка шапки
- **CSV** — три отдельных файла (problems, hosts, events)

## Установка и запуск

### Требования
- Python 3.10+  →  https://python.org/downloads
- Windows 10 / 11

### Быстрый старт
```
1. Дважды кликнуть run.bat
   (зависимости установятся автоматически)
```

### Ручная установка
```bat
pip install openpyxl
python zabbix_reporter.py
```

## Подключение к Zabbix

| Поле | Пример |
|---|---|
| URL сервера | `https://zabbix.company.com` или `http://192.168.1.10` |
| Пользователь | `Admin` (или любой с правами API) |
| Пароль | пароль пользователя |
| Проверять SSL | отключите для self-signed сертификатов |

## Необходимые права пользователя Zabbix

Пользователь должен иметь роль с доступом к:
- `problem.get`
- `host.get`
- `event.get`
- `hostgroup.get`

Стандартная роль **Zabbix User** достаточна для чтения.
