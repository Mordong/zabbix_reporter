## v3.4

**Безопасность и конфигурация:**
- 🔐 **Шифрование пароля** в `config.json` — XOR с машинно-зависимым ключом (SHA-256 от Windows MachineGuid + username + соль), префикс `enc:` отличает шифрованный от plaintext
- 📂 **Правильный путь config.json для EXE** — используется `sys.executable` когда `sys.frozen`, вместо временной папки `_MEIxxxx`
- 📂 **Единое поведение** для Python-скрипта и скомпилированного `.exe` — в обоих случаях `config.json` сохраняется рядом с исполняемым файлом
- 🛡 **Защита от копирования** — пароль, зашифрованный на одной машине, невозможно расшифровать на другой (ключ привязан к MachineGuid)
- ♻️ **Автомиграция** — legacy-пароль в plaintext из старых конфигов корректно подхватывается и перешифровывается при следующем сохранении
- 🔧 Поле `report_sections` (выбор разделов экспорта) теперь также сохраняется вместе с остальными настройками

**Исправления:**
- 🐛 Исправлен `NameError: name 'sys' is not defined` при запуске — добавлен `import sys`
- 🐛 В логе после сохранения выводится полный путь к `config.json` и индикатор шифрования

## v3.0 (финальная версия)

**Хосты и Объекты:**
- Объединение вкладок «Хосты» и «Объекты» в одну
- Новая колонка **Agent version** прямо в таблице
- Карточка хоста открывается в **отдельном окне** по двойному клику
- **Улучшенный алгоритм доступности** — для не-Agent интерфейсов проверяется свежесть данных через `item.get.lastclock`
- Колонка **Интерфейсы** показывает все интерфейсы с типом и адресом

**События:**
- Фильтры по **серьёзности** (6 чекбоксов), **хосту** и **временному интервалу**
- Корректное получение **времени восстановления** через recovery-события
- Новая колонка **Длительность**

**Дубликаты:**
- Объединение «По имени» и «Short/FQDN» в единую категорию **«По hostname»**
- Исправлен фильтр IP — больше не игнорирует `127.0.0.1` (валидный адрес для локальных агентов)
- Причина дубликата автоматически классифицируется

**Шаблоны:**
- Вкладка **Сравнение шаблонов** с трёхуровневым алгоритмом
- Вкладка **Экспорт шаблонов** в YAML/XML/JSON
- Кнопка «Загрузить шаблоны» в обеих вкладках

**Аутентификация:**
- Кнопка **💾 Выгрузить в файл** — одновременный экспорт в PDF и JSON
- Полная поддержка JIT Provisioning (group mapping, media mapping)
- Поддержка Zabbix 6.4+ через `selectProvisionGroups` / `selectProvisionMedia`

**UI/UX:**
- Увеличен размер окна до `1540×860` (минимум `1200×700`)
- Уменьшен padding вкладок — не сжимается текст
- Исправлен стиль Combobox (текст виден во всех состояниях)
- Коллапсируемые секции в левой панели через `grid_remove` (разворачиваются в правильном месте)

**Исправления:**
- `matplotlib.use("Agg")` больше не ломает `FigureCanvasTkAgg` — график строится корректно
- Исправлен дубликат `fontName` в `ParagraphStyle` экспорта сравнения
- Исправлена рекурсия при загрузке списка шаблонов
- Исправлена ошибка «Item not found» в `_tpl_exp_select_all`
- Поддержка `selectHostGroups` / `selectTemplateGroups` (Zabbix 6.2+) с fallback
